Procédure de basculement d'un poste utilisateur d'un ancien domaine Windows (ANCIEN.local) vers un nouveau domaine Active Directory (NOUVEAU.local).
Elle couvre la sortie de l'ancien domaine, l'intégration au nouveau, la mise à jour des mots de passe Active Directory et Microsoft 365,
le remplacement de l'antivirus, ainsi que la remise en ordre complète du poste utilisateur.
Deux machines interviennent : un poste administrateur pour piloter les opérations et un poste utilisateur pour la machine concernée par la migration.
